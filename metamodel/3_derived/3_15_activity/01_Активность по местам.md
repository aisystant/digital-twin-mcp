# IND.3.15.01

**Name:** Активность по местам
**Name (EN):** Activity by place
**Type:** temporal
**Format:** structured_object

## Description

Сколько дней за всё время человек был активен в каждом месте экосистемы (IWE, клуб, LMS, бот) и во всех местах вместе, текущая серия дней подряд и рекорд серии. Показывается на табло /progress в Telegram-боте (WP-417 Ф7).

**Кто пишет:** ночной расчёт Профилировщика (R28, `DS-ai-systems/profiler/scripts/recalculate_derived.py`, ключ `3_15_activity`). Источник — функция `learning.activity_summary` по журналу действий; Профилировщик читает её отдельной ролью `profiler_activity_reader` без прав на таблицы.

**Правила:**
1. **Рекорд не падает** — `record` = максимум из сохранённого рекорда и самой длинной серии по журналу (если журнал очистят, рекорд останется).
2. **Место без новых строк сохраняет прежнюю запись** — пропавший источник не обнуляет историю.
3. **Нет строк при сохранённом блоке** — блок не перезаписывается.
4. **Активный день** — день по московскому времени, в котором было хотя бы одно действие, кроме служебных событий и оценочной истории, записанной при онбординге. Неклассифицированные источники (`other`) не считаются.
5. **Бот** добавляет записи своей базы при показе; в этом блоке их нет.

**Активный день ≠ Баллы.** Активность считает дни с действиями, баллы — начисления по правилам экономики (DP.ECON.001).

## Допустимые значения

Ключи `channels`: `all` (все места вместе), `iwe`, `club`, `lms`, `bot`.

## Формат хранения

```json
{
  "channels": {
    "all": {
      "active_days": 120,
      "first_day": "2026-01-05",
      "last_day": "2026-11-13",
      "current_streak": 12,
      "longest_streak": 40,
      "record": 45
    },
    "iwe": {
      "active_days": 95,
      "first_day": "2026-02-01",
      "last_day": "2026-11-13",
      "current_streak": 12,
      "longest_streak": 30,
      "record": 30
    }
  },
  "as_of": "2026-11-14T00:40:00+00:00",
  "source": "learning.activity_summary"
}
```

Значения в примере условные (`record` 45 > `longest_streak` 40: рекорд сохранён после очистки журнала). Даты `first_day`, `last_day` — ISO-даты по Москве; `as_of` — момент расчёта.
